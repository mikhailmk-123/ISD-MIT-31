# ISD-MIT-31
**Information Systems and Databases (ISD)** — це навчальна дисципліна, що вивчає принципи проєктування, реалізації та експлуатації інформаційних систем з використанням сучасних баз даних. У межах курсу розглядаються моделі даних, методи логічного й фізичного проєктування баз даних, мови запитів, транзакції, цілісність і безпека даних, а також архітектури інформаційних систем і їх взаємодія з прикладним програмним забезпеченням. Особлива увага приділяється аналізу вимог, оптимізації доступу до даних, масштабованості та надійності систем, що забезпечують підтримку управлінських, наукових і бізнес-процесів.

Завдання:
Для успішного виконання лабораторної роботи необхідно пройти наступні етапи: 1) <u>Частина 1: Оптимізація продуктивності запитів</u> — встановити MongoDB та розширення для VS Code, створити базу performance_test та колекцію sales, після чого згенерувати 100 000 документів за допомогою Python-скрипту. Провести порівняльний аналіз запитів без індексів та з використанням одиничних і складених індексів для оцінки приросту продуктивності. 2) <u>Частина 2: Налаштування реплікації у MongoDB</u> — запустити три екземпляри серверів, ініціалізувати Replica Set, перевірити доступність даних на Secondary-вузлах та дослідити процес автоматичного вибору нового лідера при відключенні Primary. 3) <u>Частина 3: Реалізація шардінгу у MongoDB</u> — налаштувати екземпляри у режимі шардів, додати їх через MongoDB Shell та перевірити рівномірність розподілу даних для оцінки ефективності горизонтального масштабування системи.

Мета:
Ознайомитися з методами підвищення продуктивності MongoDB. Навчитися використовувати індекси для оптимізації запитів. Дослідити механізми <u>реплікації та шардінгу</u>.
