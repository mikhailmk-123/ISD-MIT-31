# ISD-MIT-31
**Information Systems and Databases (ISD)** — це навчальна дисципліна, що вивчає принципи проєктування, реалізації та експлуатації інформаційних систем з використанням сучасних баз даних. У межах курсу розглядаються моделі даних, методи логічного й фізичного проєктування баз даних, мови запитів, транзакції, цілісність і безпека даних, а також архітектури інформаційних систем і їх взаємодія з прикладним програмним забезпеченням. Особлива увага приділяється аналізу вимог, оптимізації доступу до даних, масштабованості та надійності систем, що забезпечують підтримку управлінських, наукових і бізнес-процесів.

**Завдання:** 
Для успішного виконання лабораторної роботи кожен студент має реалізувати завдання на основі **власної інформаційної системи**, створеної у попередній роботі, враховуючи наступні етапи: 1) **<u>Створення користувацького типу даних</u>**: визначити та створити тип (наприклад, _ENUM_ або _Composite Type_), що відповідає логіці системи, та інтегрувати його у структуру таблиць для забезпечення **розширюваності** без порушення цілісності даних. 2) **<u>Створення користувацької функції або агрегату</u>**: реалізувати об'єкт для виконання **розширених обчислень**, які виходять за межі стандартних можливостей SQL, та протестувати його ефективність. 3) **<u>Створення тригерів для логування змін та автоматизації</u>**: розробити _таблицю логування_ та написати тригерні функції на **PL/pgSQL** для автоматичного відстеження операцій _INSERT, UPDATE, DELETE_, а також для автоматичного оновлення залежних таблиць, мінімізуючи дублювання даних. 4) **<u>Оновлення діаграми бази даних</u>**: внести актуальні зміни до **ER-діаграми**, додавши нові сутності та зв’язки, щоб візуалізувати оновлену архітектуру системи. 5) **<u>Перевірка роботи</u>**: виконати набір тестових _SQL-запитів_ для демонстрації коректності логування, роботи функцій та тригерів, а також підготувати **порівняльний аналіз**, який підтвердить покращення ефективності бази даних завдяки впровадженим рішенням.

**Мета:** 
Закріпити знання з **<u>розширюваності PostgreSQL</u>**. Навчитися створювати _користувацькі типи даних_. Реалізувати власну _користувацьку функцію або агрегат_. Створити **тригери** для логування змін у базі даних. Автоматично оновлювати пов’язані таблиці чи заповнювати значення. Оновити **діаграму бази даних** відповідно до виконаних завдань. Перевірити **коректність роботи** реалізованих об’єктів через виконання тестових _SQL-запитів_.
